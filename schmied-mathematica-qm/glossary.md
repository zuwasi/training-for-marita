# Glossary: Using Mathematica for Quantum Mechanics (Schmied)

**Anonymous function**: `#^2&`; `#` is the first argument, `##` all arguments, `#0` the function itself (Ch 1)
**Apply (`@@`)**: replaces a list's head with a function, e.g. `Plus @@ list`, `Dot @@ {A,B,C}` (Ch 1)
**Arnoldi method**: iterative solver for a few extremal eigenpairs of large sparse matrices; lowest states via `-Eigensystem[-H, k, Method->{"Arnoldi","Criteria"->"RealPart"}]` (Ch 1, 3, 4)
**Basis conversion matrix X**: Xnj = √(2/(nmax+1)) sin(πnj/(nmax+1)); symmetric, orthogonal, self-inverse; implemented by `FourierDST[·,1]` (Ch 4)
**Breit-Rabi diagram**: the 8 hyperfine energies of 87Rb versus Bz, from weak-field |F,MF⟩ to strong-field |MI,MJ⟩ (Ch 3)
**Chemical potential μ**: Lagrange multiplier for normalization in the Gross-Pitaevskii equation; μ = Ekin + Epot + 2Eint (Ch 4)
**Completeness relation**: Σi |i⟩⟨i| = 𝟙; inserting it turns abstract operators into matrices (Ch 2)
**Computational basis**: orthonormal basis {|i⟩} giving matrices Aij = ⟨i|A|j⟩ and vectors ψi = ⟨i|ψ⟩ (Ch 2)
**Contact interaction**: g·δ(x1−x2); matrix elements from quartic overlap integrals via a 4D DST; no effect on fermions (Ch 4)
**CTRL gate**: 𝟙 + (Π of |1⟩⟨1| projectors on control qubits)·(A − 𝟙) (Ch 3)
**Delayed assignment (`:=`)**: stores the right-hand side unevaluated, re-evaluated on each use (Ch 1)
**Detuning Δ**: ω − (Ei−Ej)/ħ, drive frequency minus transition frequency (Ch 3)
**Dicke basis**: joint eigenstates |S,M⟩ of S² and Sz, ordered by decreasing M (Ch 2, 3)
**Dressed states**: atom+field eigenstates split by |Tij| under resonant driving (Ch 3)
**DST-I (`FourierDST[v,1]`)**: type-I discrete sine transform; the O(n log n) switch between momentum and position bases (Ch 4)
**Dyson series**: time-ordered expansion of the propagator; not unitary when truncated (Ch 2)
**Energy cutoff**: E_nmax = π²ℏ²nmax²/(2ma²); physics above it is not represented (Ch 4)
**Entropy of entanglement**: log₂ von Neumann entropy of a reduced density matrix (Ch 3)
**Finite-resolution position basis**: |j⟩ = √Δ Σn φn(xj)|n⟩, local states at grid points xj = jΔ (Ch 4)
**FullForm**: internal expression tree, e.g. `a/b` is `Times[a, Power[b,-1]]` (Ch 1)
**Generalized Rabi frequency**: Ω = √(|Tij|²/ħ² + Δ²) (Ch 3)
**Gross-Pitaevskii equation**: non-linear Schrödinger equation [T + V + κ|ψ|²]ψ = μψ for a BEC (Ch 4)
**Immediate assignment (`=`)**: evaluates the right-hand side once at definition time (Ch 1)
**Imaginary-time propagation**: repeated e^{−δβ H} plus renormalization; converges to the ground state (Ch 4)
**Incomplete basis set**: truncated basis whose Σ|i⟩⟨i| = P is only a projector; Q = 𝟙 − P is neglected (Ch 2)
**Interaction picture**: time-dependent basis e^{−iEi t/ħ}|i⟩ for H = H0 + H1(t); removes fast phases (Ch 2)
**Jaynes-Cummings model**: two-level atom coupled to one cavity mode by ħg(S₊a + a†S₋) (Ch 5)
**KroneckerProduct**: tensor product of operators/states; first factor is the slowest index (Ch 2)
**Locality approximation**: f(x)ϑj(x) ≈ f(xj)ϑj(x); makes V̂ and x̂ diagonal on the grid (Ch 4)
**Magic field**: Bz ≈ 3.22896 G where the 87Rb |1,−1⟩↔|2,1⟩ splitting is first-order field-insensitive (Ch 3)
**Magnus expansion**: U = exp[Σk Ωk] from commutators of H(t); stays unitary when truncated (Ch 2)
**MatrixExp**: true matrix exponential Σ Aⁿ/n!, not element-wise `Exp` (Ch 2)
**Memoization**: `f[x_] := f[x] = ...`; a function that stores its own results as new definitions (Ch 1)
**Mixed basis (mixed representation)**: kinetic operator built in momentum basis, potential on the grid, joined by DST (Ch 4)
**Momentum basis**: square-well eigenstates φn(x) = √(2/a) sin(nπx/a), where T̂ is exactly diagonal (Ch 4)
**Natural units**: units chosen so key constants (ℏ, µB) equal 1; physical values enter as `Quantity[...]/Unit` (Ch 1, 3, 4)
**Non-separable Hamiltonian**: a term (e.g. Bx Sx) mixes spin sectors, so motion and spin must be solved together (Ch 5)
**Particle interchange operator Π**: ψ(x1,x2) → ψ(x2,x1); eigenvalue +1 bosons, −1 fermions (Ch 4)
**Pattern (`x_`)**: named blank matching any expression; restrict with `x_Integer`, `x_?NumericQ`, `x_ /; cond` (Ch 1)
**Pseudo-spin**: two atomic levels written as spin-1/2, S₊ = |e⟩⟨g| (Ch 5)
**Quadratures X̂, P̂**: X̂ = (a+a†)/√2, P̂ = (a−a†)/(i√2), [X̂,P̂] = i (Ch 5)
**Quantum Fourier Transform**: circuit of Hadamards, controlled phase rotations and SWAPs with matrix 2^(−n/2) e^(2πijk/2ⁿ) (Ch 3)
**Quantum phase estimation**: Hadamards, controlled U^(2^k), inverse QFT; reads phase φ to t bits (Ch 3)
**Rashba coupling**: momentum-spin interaction p̂x⊗Ŝy − p̂y⊗Ŝx (Ch 5)
**Reduced density matrix**: ρA = TrB ρAB, via the book's `rdm` / `traceout` functions (Ch 2)
**Replacement rule**: `x -> y` (immediate) or `x :> y` (delayed), applied with `/.`; `//.` repeats until fixed (Ch 1)
**Rotating-wave approximation (RWA)**: drop fast counter-rotating terms, keep near-resonant couplings (Ch 3)
**Separable Hamiltonian**: all terms diagonal in spin; splits into independent spin-up/down problems (Ch 5)
**SparseArray**: stores only nonzero entries; essential for large Hamiltonians (Ch 1)
**Split-step (Trotter) propagation**: e^{τ(V+T)} ≈ e^{τV/2}e^{τT}e^{τV/2}, error O(τ³) per step (Ch 4)
**Transverse Ising model**: H = −(b/2)Σ Sx(k) − Σ Sz(k)Sz(k+1); quantum phase transition at b = ±1 (Ch 3)
**Variational principle (truncated basis)**: ground energy in a truncated basis is an upper bound, decreasing with basis size (Ch 2)
**Wigner quasi-probability distribution**: real phase-space function W(x,k); negativity marks nonclassical states (Ch 4, 5)
